# People Memory - Native Android Application with Firebase
Private, offline-first personal memory manager for Android phone contacts with Firebase Authentication (Google Sign-In) and Cloud Firestore persistence.

## How to Run in Android Studio
1. Open Android Studio Koala / Ladybug (2024.1+).
2. Choose "Open" and select this project directory.
3. Wait for Gradle Sync to complete with google-services.json.
4. Press Run (Shift + F10) on a device or emulator running Android 8.0+ (API 26+).
